## 闂鍥炵瓟

1. FATROP 插件是否可用：plugin=是, toy solve=是。
2. FATROP limited-memory 是否真正生效：hessian_approximation accepted=否。若为否，本轮按要求停止 FATROP 正式对比。
3. manual IHSID 与 standard IHSID 是否公平：manual IPOPT solverSuccess=是, engineeringPassed=是, objectiveDiffAtX0=0。
4. IHSID-MANUAL-FATROP 是否初始化/求解/工程通过：init=是, solve=否, engineering=否。
5. FATROP 失败位置：FATROP_LIMITED_MEMORY_UNAVAILABLE；failureReason=当前 CasADi FATROP 接口不接受 hessian_approximation=limited-memory，按要求停止 FATROP 对比。。
