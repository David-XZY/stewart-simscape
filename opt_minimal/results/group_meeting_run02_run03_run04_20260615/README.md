# Run02 / Run03 / Run04 组会图说明

三组结果使用同一条 `7.5 s` 参考轨迹：

`examples/ihsid_40x20_limited_memory/simscape_references.mat`

## 推荐讲图顺序

1. `01_run02_run03_run04_metrics.png`
   - 作为主结果图。
   - Run02 位姿反馈力输入的误差最小。
   - Run04 在 Run03 理想腿长串级控制上加入位姿外环后，各项误差约降低一半。

2. `02_run02_run03_run04_time_history.png`
   - 作为时间历程证据图。
   - 展示腿长、平移和转角误差在完整轨迹中的变化。
   - 约 `5 s` 附近的短时波动可用于讨论轨迹阶段切换和闭环瞬态。

3. `03_run02_run03_run04_structures.png`
   - 用于解释三种控制结构为什么产生不同结果。
   - Run02：位姿反馈产生腿力，包含逆动力学前馈。
   - Run03：仅使用理想腿长串级控制。
   - Run04：在 Run03 基础上增加位姿外环修正。

## 核心定量结论

| 指标 | Run02 | Run03 | Run04 | Run04 相对 Run03 |
|---|---:|---:|---:|---:|
| 等效位姿 RMS / mm | 0.00463 | 0.38299 | 0.19320 | 降低 49.55% |
| 等效位姿峰值 / mm | 0.03478 | 1.05330 | 0.52892 | 降低 49.78% |
| 平移误差峰值 / mm | 0.02747 | 0.96867 | 0.48557 | 降低 49.87% |
| 转角误差峰值 / deg | 0.00399 | 0.12070 | 0.06061 | 降低 49.79% |
| 腿长误差峰值 / mm | 0.04858 | 1.76272 | 0.89567 | 降低 49.19% |

## 汇报时需要说明的边界

Run02 使用腿力作为物理输入；Run03 和 Run04 直接使用理想腿长输入。因此三者适合比较控制结构对跟踪误差的影响，但不能把 Run03、Run04 的结果直接理解为真实执行器性能。
