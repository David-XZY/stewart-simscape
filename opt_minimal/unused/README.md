# unused 历史归档

此目录保存仍有追溯价值、但不属于当前 standard IHSID 主线的实现。活动入口、活动源码和活动测试不得调用这里的文件。

- `comparisons/`：CHSID、DMSID、ED、网格/Hessian 和旧求解器比较。
- `fatrop/`：FATROP 原生、manual 结构和诊断实验。
- `legacy_hs/`：更早的压缩 HS、预对准、fmincon/SQP 和旧测试。
- `reporting/`：历史比较报告与论文图生成脚本。

重复测试、调试矩阵、失败结果和过时副本已直接删除；整理前完整状态保存在远端分支 `backup/pre-opt-minimal-ihsid-20260607`。
