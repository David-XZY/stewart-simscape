# Historical Stewart source archive

Historical branch-head source snapshots, local source modifications and unique source recovered from legacy code packages. This branch has an independent root commit; existing branches and history are unchanged.

`archive_manifest.json` maps every retained file to its original path or commit and SHA256. Package-only objects are content-addressed. Original LICENSE/COPYING/NOTICE files are retained with the source. This collection is a historical source archive, not a standalone validated release. Current thesis code and private development snapshots are stored separately in the private thesis repository. Experimental data and generated JIT files are excluded.
