# SC-FG-MHE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 SC-FG-MHE 参数估计主线，并生成可测试的比较、消融、图表和论文方法文档。

**Architecture:** 在 `controller/factor_graph_estimation/` 中实现独立滑窗估计器；复用现有 Stewart 运动学、Jacobian、IMU 仿真、UKF benchmark 和动力学工具；通过可开关 residual 支持无动力学、含动力学、鲁棒核、执行器参数估计四类消融。

**Tech Stack:** MATLAB 函数脚本、`lsqnonlin`、现有 `opt_minimal/core` 与 `controller/ukf_pose_estimation` 工具、MATLAB `.mat/.csv/.fig/.png` 导出。
