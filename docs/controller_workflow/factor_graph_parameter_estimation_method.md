# 基于 Stewart 闭环约束的因子图滑窗参数估计方法

## 为什么不继续以 UKF 作为核心方法

现有 UKF 是一步预测和一步更新的递推滤波器，适合在线状态估计，但对慢变物理参数、窗口内多源约束和异常点鲁棒处理的表达能力有限。本文新增的 SC-FG-MHE 不替代 UKF 的工程基线价值，而是把 UKF 作为对照组，重点研究滑动窗口优化是否能同时提高位姿估计和参数辨识能力。

## 数学模型

在长度为 `W` 的滑动窗口内，优化变量为：

`X = {q_k, qd_k, qdd_k, bL, bAtt, ba, bg, dm, dc, kF, tauF, cF}`。

目标函数为多类 residual 的加权鲁棒最小二乘：

`min_X sum rho(||r_leg||^2) + rho(||r_att||^2) + rho(||r_imu||^2) + ||r_geom||^2 + rho(||r_dyn||^2) + ||r_act||^2 + ||r_param||^2`。

其中 `rho` 可选 Huber 鲁棒核。

## 各类因子的物理意义

- 腿长因子：用编码器腿长约束平台位姿，同时估计六条腿长偏置。
- IMU 姿态因子：利用姿态解算值约束 roll、pitch、yaw，并估计姿态小偏差。
- IMU preintegration-like 因子：用短时加速度和角速度建立窗口内运动连续性。
- Stewart 几何闭环因子：通过腿长边界和 Jacobian 最小奇异值抑制不合理构型。
- 动力学因子：用负载质量、质心、加速度和广义力需求解释平台运动。
- 执行器因子：用等效力增益和阻尼解释输入到支链力之间的差异。
- 参数先验因子：约束慢参数在相邻窗口之间平滑变化。

## 滑窗优化变量

快状态包括每个时刻的 `q`、`qd` 和可选 `qdd`。慢参数包括 `bL`、`bAtt`、`ba`、`bg`、`dm`、`dc`、`kF`、`tauF` 和 `cF`。当前实现把慢参数设为窗口内常值，并通过上一窗口估计形成先验。

## 与 UKF 的区别

UKF 的核心是递推滤波，状态估计随时间单步推进。SC-FG-MHE 的核心是窗口优化，同一窗口内多个时刻的状态和参数共同求解，因此可以直接融合几何闭环、IMU 连续性、动力学和执行器一致性 residual。

## 消融实验设计

消融实验包括：

1. 无动力学因子的 FG-MHE。
2. 加入动力学因子的 FG-MHE。
3. 加入动力学因子和鲁棒核的 FG-MHE。
4. 加入执行器参数估计的 FG-MHE。
5. 完整 SC-FG-MHE。

## 对比实验设计

对比方法包括纯运动学解算、稳定 UKF、腿长偏置 UKF、无动力学 FG-MHE、含动力学 FG-MHE、鲁棒 FG-MHE 和执行器参数 FG-MHE。统一输出平移误差、姿态误差、腿长偏置误差、IMU 零偏误差、负载参数误差、执行器增益误差、计算时间和失败窗口数。

## 可写入硕士论文的创新点表述

本文提出一种面向 Stewart 并联平台的闭环约束因子图滑窗参数估计方法，将腿长测量、IMU 短时运动先验、平台几何闭环、动力学一致性、执行器等效参数和慢变参数先验统一为非线性最小二乘 residual。相比递推 UKF，该方法能够在有限窗口内联合估计快状态和慢参数，并通过鲁棒核降低异常测量对参数收敛的影响。
