# 第五章独立速度诊断

本目录为开发验证。正式控制器、物理配置、教师数据、模型及旧结果保留；本目录的运行不计入正式1440次实验。

测试内容：MATLAB及模型复用；IHSID四组初值逐组移位复用；Hermite参考及密集约束检查批量计算；20步DDIM只去噪后对四个控制增量候选排序，再对一个候选进行有限次联合优化；优化10 Hz刷新、输入50 Hz执行。

每个新输入序列必须通过原控制器的完整动力学、物理及终端检查。没有通过时使用原安全QP，并明确记录其没有安全保证。失败时也保留刷新时钟，避免每拍重复优化。失效初值可重建为原有动力学制动初值；这不是任务参考轨迹。

入口在仓库根目录执行：

```matlab
addpath('chapter5'); addpath('chapter5/performance');
ch5SpeedWorker
```

向 `chapter5/artifacts/performance_probe/worker_command.json` 写入独立任务标识、`action: "run"` 和以下函数名，已有进程执行后保持空闲，不按任务重启MATLAB。

- `ch5SpeedBudgetStudy`：相同初始状态/实测微扰状态下的3、10、30次NLP预算，理想及非理想执行器。
- `ch5SpeedCorrectedClosedLoop`：修正版理想执行器固定/切换目标，15秒Simscape；发生物理违反时提前停止并保留数据。
- `ch5SpeedPlanningPaired`：同状态冷启动/热启动配对，原/批量密集检查等价性和耗时。
- `ch5SpeedTailStudy`：下一规划力加制动延续的独立修复试验；仍通过原检查。实际两个任务均提前出现物理违反，未通过验收。

`ch5SpeedBenchmark`、`ch5SpeedPlanningBenchmark`、`ch5SpeedClosedLoop` 为早期尝试，原始结果与对应源代码快照保留在工件目录。它们已暴露静态候选、终端不可行、频繁回退及仿真发散，不能当作通过验收。

重新生成报告：

```powershell
& chapter5/.venv/Scripts/python.exe chapter5/performance/report.py
```

报告位于 `chapter5/artifacts/performance_probe/report/index.html`，包含逐调用CSV、闭环CSV、图、原始MAT及文件哈希清单。构建耗时与控制耗时分开；同步仿真的15秒运动不是墙钟15秒。100毫秒预算是否达标必须看实测；候选通过或预测终点很近不等于实测到达。该诊断不能推出移动障碍安全或组合方法稳定性。

本轮结论：批量密集检查约6.02秒降至0.067秒；同状态四初值冷启动39.33秒、热启动23.23秒，均通过后验检查。快速控制没有达到100毫秒，完整/提前停止的闭环试验均未通过。保留此目录作为开发诊断，正式版本继续使用原控制源代码，不把这些诊断结果混入正式实验。
