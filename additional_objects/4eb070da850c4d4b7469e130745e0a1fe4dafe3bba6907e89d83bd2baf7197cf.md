## 50 MB 内保留数据的方式

完整保留逐任务指标、失败状态、参数清单、训练标签、模型权重、训练记录、独立审计摘要和现有图/动画。数百 MB 的逐点导出 JSON、数 GB 的稠密 MAT、中间快照 ZIP、重复轨迹、第三方二进制依赖不整份放入包内。

小批 `pilot_v4` 保留完整可加载 `model.json` 权重，省略含重复权重和优化器状态的 `checkpoint.pt`；正式 `formal_v1` 的两种权重文件均保留。因此本包可加载两阶段模型，但不能直接恢复小批训练的原优化器状态。

轨迹改以样条控制点或 IHSID 的位姿/速度、加速度及驱动力配点保存，数值保持原始 double 精度，没有为缩小体积而舍入或下采样。相同候选池和轨迹去重存储。由包内重建函数可重新计算任意指定时刻的轨迹；分离法向、稠密求值缓存和完整优化器内部对象未保留在紧凑文件中。原始大文件仍在原工程结果目录。

硬超时或崩溃前未保存候选的 177 项，使用此前冻结条件和种子离线重建的控制点，索引中 `regenerated=true`。它们不能被解释为当时成功保存的轨迹或成功规划，原失败及计时始终保留。额外参考的 `accepted_checkpoint` 也不表示进程正常结束，须结合原 `completion.json` 和 `runtime_audit.json`。

## 读取紧凑轨迹

在 MATLAB 中把当前目录切到本包根目录：

```matlab
addpath('diffusion','study');
s = load('compact_data/compact_trajectories.mat');
% records 是记录，pools 是候选控制点数组，bundles 是轨迹系数。
% 编号采用 MATLAB 1-based；编号 0 表示没有保存相应数据。
idx = find(cellfun(@(r) strcmp(r.stage,'frozen_v1') && ...
    strcmp(r.id,'id_simple_01__diff_fast__k64__r1'),s.records),1);
r = s.records{idx};
cp = s.pools{r.candidatePool};       % 6 × 16 × 候选数
b = s.bundles{r.best};
tr = sgReconstruct(b,linspace(0,b.T,1001));
plot3(tr.q(1,:),tr.q(2,:),tr.q(3,:)); grid on;
```

紧凑 MAT 已重新读取，核对候选、轨迹系数和索引与导出内存逐项一致。原始逐任务 JSON/CSV 和原模型文件按原字节复制，并在文件清单中提供哈希。

## 复现依赖及版本

包中包含源代码、训练数据、可加载权重、任务清单和运行入口，不包含 MATLAB、CasADi/CoinHSL、PyTorch/CUDA 等安装包。实际实验使用 MATLAB R2019a / 本机 R2025b；配置外部依赖参见两个工程 README。只读轨迹重建无需启动 NLP 求解器。

新实验使用独立运行名，保留本包正式结果。正式模型没有重新训练，主数值指纹、模型指纹和额外参考版本分别保存在各自协议中。早期正式结果和本轮结果的时间、候选数量、参考目标及修正方式不同，不能直接拼接成统一速度比较。
