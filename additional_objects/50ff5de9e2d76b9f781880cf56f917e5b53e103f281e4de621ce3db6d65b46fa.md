# Frozen-model generalization study

The original `diffusion/` implementation and trained assets are unchanged.
All numerical study functions are under `study/`. MATLAB R2019a and CasADi
3.7.2 / MA27 are required. Existing `formal_v1` weights and training labels
are loaded by `sgAssets`; no training is performed.

## Reproduce

```matlab
addpath('diffusion','study');
test_sg_core; test_sg_repair; test_sg_edges; test_sg_integration;
sgPrepare('reproduction_v1');
```

On `ws`, set `STEWART_DEPENDENCY_ROOT` to
`D:/XieZhenyu/stewart-simscape-abfd`. Then, from the repository root:

```powershell
$studyDeadline = [DateTime]::UtcNow.AddHours(18).ToString('yyyy-MM-ddTHH:mm:ss') + '+00:00'
D:/XieZhenyu/envs/stewart-abfd/Scripts/python.exe study/run_study.py --run reproduction_v1 --deadline $studyDeadline
```

The supervisor launches at most two hidden MATLAB processes. It enforces
per-job wall limits and a fixed compute deadline. Its default deadline is
2026-09-17 03:46:51 UTC, reserving six hours from the agreed 24-hour window
for analysis and delivery. Use `--deadline` for a new independently named run.
Resume uses the same manifest, implementation fingerprint, model and jobs.
The commands above create a separate reproduction. Keep `frozen_v1` intact;
its original deadline is not extended by the reproduction example. The
`studyDeadlineEpoch` field describes the original study window; for a new run,
the explicitly supplied `computeDeadlineEpoch` controls execution.
Only remove a stale `supervisor.lock` after verifying that its PID is gone.

## Records and interpretation

`results/study/<run>/manifest.{mat,json}` contains 172 known-parameter cases,
116 unknown-parameter audits and eight permutation probes. `jobs.json` has
the predetermined interleaved order, six primary methods, candidate-count
experiments, eight legacy-checker ablations, and eight longer IHSID references.
Boundary-invalid tasks are retained. No task is selected using path success.

Each job has `online.mat`, `result.mat`, and `result.json`. Required online
validation is timed. Independent audit, raw-candidate census, and quality
metrics are separately timed research diagnostics. Unknown-parameter reuse
retains the original planning time; true parameters are passed only to audits.
`online_progress.json` preserves completed IHSID attempts before hard timeout.
`progress.json` reports completion; absent result files are unfinished.
Hard process failures may have only partial files. If `online.mat` survives an
audit failure, export restores its measured time in `timing_details.json` and
audits the retained output; it preserves the original failed run status.

Both IHSID methods optimize the same fixed task reference and constraints.
Fixed engineering scales in the objective are normalization constants, not
actuator limits. Every feasibility limit is read from the current model.
Fast methods choose the best accepted 61-point common score within budget;
all reported final quality metrics are recomputed at at most 5 ms spacing.
First feasible and subsequent improved outputs are retained with timestamps.
Any known-model disagreement with independent audit creates `safety_stop.json`
and stops the study. Unknown-model audit failures are expected study outcomes.

The validator uses support planes as separation certificates. Failure to find
a certificate is a rejection, not a proof that collision is unavoidable.
Dense validation is not a continuous-time safety proof. Mechanical work is a
load proxy, not electrical energy. These experiments do not test tracking.

## Summaries and figures

After computation, `python study/collect_study.py frozen_v1 --full` creates a
snapshot of completed records and trajectory MAT files. Copy it to the same
run directory on the development computer, extract, then run:

```matlab
sgExport('frozen_v1',true);
```

```text
python study/summarize_study.py results/study/frozen_v1
python study/plot_trajectories.py results/study/frozen_v1
python study/audit_records.py results/study/frozen_v1 --require-fresh-audit
```

These postprocessing helpers do not alter the frozen numerical fingerprint.
The second argument requests an additional audit in the local MATLAB process.
It audits selected, first-feasible and improved outputs independently, with
cached records keyed by trajectory job, true model and audit implementation.
A known-model disagreement stops export immediately. This research audit is
separate from the required online checks and never subtracted from online time.
The report retains unfinished jobs, failure reasons, paired quality metrics,
parameter strata, candidate counts, timing checkpoints, and checker ablations.
Trajectory figures select the first lexical paired successful domain task in
each scene. The full task tables, rather than selected figures, support claims.

If a hard timeout or process failure lost candidates before they were saved,
add `study/post` to the MATLAB path and run
`sgRegenerateMissingCandidates('frozen_v1')`. Its separate
`regenerated_candidates` directory explicitly labels offline regeneration from
the frozen planning conditions and seed. It never changes original outcomes,
timings or audit counts, and is not represented as an original saved output.

## Checkpointed long references

The original reference loop retains its best trajectory in memory until it
returns. A later timeout or native process failure can discard that output.
`study/reference/sgPlanCheckpointed.m` is a separate copy whose only planner
changes are its function name and persistence after each improved acceptance.
The primary numerical fingerprint remains unchanged. Its old-development
persistence test is `test_sg_checkpoint` with `study/reference` on the path.

After the primary supervisor has stopped, `python study/run_reference.py --run
frozen_v1` runs the same eight predefined reference jobs again, with the same
600-second budgets and at most two processes. It uses the original compute
deadline. A new reproduction can supply its own `--deadline`. Results and
source fingerprints go in `reference_checkpointed_v1`; never pool minimum
costs with the original reference attempts. A later process failure remains
documented even when an earlier checkpoint is physically valid.

Run `sgReferenceExport('frozen_v1')` with `study/reference` on the MATLAB path
to independently audit retained checkpoints, then rerun the Python summary.
`long_reference_comparison.csv` compares those available references with the
primary 180-second IHSID and fast outputs; it is not a global-optimum claim.
