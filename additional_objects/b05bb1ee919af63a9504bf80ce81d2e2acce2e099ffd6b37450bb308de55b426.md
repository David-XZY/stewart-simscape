# 原始控制扩散诊断及预稳定表示

本目录 V73–V75 为开发研究，正式实验仍须独立冻结。现有生产入口、旧模型、失败试验和已保存时序保留。MATLAB 使用原有常驻 worker，不逐次重新初始化工程。

## 决策变量及可逆性

令增广变量 ξ_j=[x_j;u_{j-1}]，ξ_s 为当前位姿对应的静态平衡，L 为该平衡附近增广 Riccati 输入增量增益。扩散学习创新量 v_j，通过同一物理模型展开：

    Δu_j = v_j - L(ξ_j-ξ_s)
    u_j = u_{j-1} + Δu_j
    x_{j+1} = f_d(x_j,u_j)

给定初态和上一指令，任何 ΔU 均可通过展开及 v_j=Δu_j+L(ξ_j-ξ_s) 编码；解码没有 QP、限幅或终端修复。V 对 ΔU 的 Jacobian 为块下三角且对角块为 I，行列式为 1。因此可将创新坐标中的先验原样转回控制增量先验；最终输出仍为直接支链力，状态轨迹仍是动力学结果。局部增益与采样检查不构成全局安全或稳定性证明。

## 已定位的实现问题

1. 固定验证位姿的开环增广极点半径为 1.12–1.18。1.2 s 开环力展开放大微小误差，力域 MSE 接近不等于状态轨迹有效。
2. 旧物理代理只选择 11 个归一化后最近的机械约束行，无法保证加速度等类别出现。V75 每个带符号的约束类别均保留标签轨迹的最不利节点，包括 37 个机械类别及 24 个指令/增量类别，另外保留障碍类别。
3. 旧训练终端导数固定了辅助位姿，而检查会更新 q_s=q_H；修复该关系的导数。终端平方误差单独加权，避免 log 压缩严重终端缺陷。
4. 单步随机时刻重建损失与实际连续 20 次 DDIM 输出存在差别。V75 在完整采样图上训练，仍只使用训练任务更新参数，验证任务选检查点。

## 顺序及入口

首次复现须使用新实验目录/版本，脚本拒绝覆盖已有模型、候选和状态记录。

1. 通过 `dispatch.py` 向已运行 MATLAB worker 顺序提交 `ch5SpeedForceSensitivityV73`、`ch5SpeedForceDataV73`。固定已有 23 个合格验证标签进行扰动，完整转换既有 1029 个合格训练/验证窗口。
2. 使用 `chapter5/.venv/Scripts/python.exe chapter5/reduced/force_v62/innovation_v74.py` 训练首轮模型，保留失败的初次启动记录。首轮 300 轮结束后，提交 `ch5SpeedForceRawV74` 和 `ch5SpeedForceRawClosedV74`。
3. 提交 `ch5SpeedForceGeometryV75`，然后执行 `innovation_v75.py` 在完整 20-DDIM 图上继续训练 200 次，批量 32。该脚本冻结起始检查点、数据、配置及源码身份。
4. 完成后提交 `ch5SpeedForceRawV75`、`ch5SpeedForceRawClosedV75`，原始候选检查包括旧的一个标签失败条件，四个噪声全部保留；只有 MATLAB/Python 一致性通过后再提交 `ch5SpeedForceFullV75`。
5. `report_raw_v74.py` 和 `report_raw_v75.py` 从原始 JSON 重算逐候选 CSV、图和 HTML，并记录相关源码/模型/标签哈希。

V76 另执行 `conditioning_v76.py`：训练时恒定的 66 个条件列不能辨识输入权重，故将其随机残留权重确定性归零。旧的 96 个 PyTorch 样本逐值不变；这不能当成另一轮 96 次物理实验。`ch5SpeedForceConditionV76` 对 28 个同噪声的新速度条件进行独立 MATLAB 完整检查和推理一致性检查；`ch5SpeedForceFullV76` 只重复同一 15 s 非理想执行器移动障碍任务；最后 `ch5SpeedForceFinalizeV76` 恢复 worker、清理已保存的过程数据，`report_raw_v76.py` 生成当前汇总报告。完整障碍观测仍传给物理预测优化，未覆盖的网络条件记录在诊断中。归零不是学习移动障碍。

原始候选的完整接受率、内部物理接受率、经过约束优化后的接受率、闭环到达率必须分别报告。原始候选闭环允许安全 QP 回退，但不调用预测 QP 或尾部修复；回退不能算作扩散成功。完整闭环仍沿用原约束优化及失败恢复。

## 文献及适用边界

- [预稳定预测控制](https://onlinelibrary.wiley.com/doi/10.1002/adc2.102)：改善困难开环预测；本项目的执行器增广输入增量编码是具体调整。
- [PDP](https://tml.stanford.edu/PDP.github.io/)：讨论物理动作模仿中的累积误差和扰动恢复教师覆盖；本轮未实现其完整训练流程。
- [DPCC](https://proceedings.mlr.press/v283/romer25a.html)：模型约束处理是组合算法的一部分，原始离线扩散样本不自动满足新约束。

本轮仅为种子 5101 的开发模型，训练和验证移动障碍覆盖仍为零。代理采用控制节点而非完整内部积分网格；完整物理审核包括内部网格、执行器瞬态、终端区域及局部下降。不可用这轮结果宣称 1440 次正式实验完成、全局安全、稳定性或墙钟实时性。
